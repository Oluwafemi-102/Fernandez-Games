# 🎮 Fernandez Games

**Fernandez Games** is a collection of simple and fun games built as a front-end project.  
The goal of this project is to practice **HTML, CSS, and basic game layout design** while combining multiple games into a single platform.

Each game is presented with a clean interface and easy navigation.

---

## ✨ Project Features

- 🎯 Multiple games in one project
- 🕹️ Simple and user-friendly game selection screen
- 🎨 Clean and colorful UI design
- 📱 Partially responsive layout for different screen sizes
- 🧠 Beginner-friendly and educational

---

## 🕹️ Games Included

- 🪨 Rock Paper Scissors
- ❌⭕ Tic Tac Toe
